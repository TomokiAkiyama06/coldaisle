## 判定のときに直したこと

採取の CSV の `ts_ms` 列が ms ではなくナノ秒（19 桁）で記録されていた。`rss-sample.sh` の `date +%s%3N` が、
導入先の uutils coreutils の `date` では `%3N` の桁数を無視するため（数字だけなので、スクリプトの検査も通った）。
そのままでは「CSV が期間を覆っていない」で判定不能になるので、元の CSV を残したまま、時刻の列を先頭 13 桁（ms）に切った写しで判定した
（19 桁でない行は 0。ほかの列は変えていない）。スクリプトの修正は #407。
