## 1. Context

AGENTS.md の「絶対に守るルール」1 は、**LLM に書き込み・実行の権限を与えない**ことを
求めている。要件 FR-503 も v1 で書き込み・実行系のツールを定義しないと定める。

同時に FR-504 が「生の時系列をプロンプトに直接投入しない。集計済みの統計量に
落として渡す」と定めている。**長大な数値テーブルに対する算術は不安定**であり、
「2万行のCSVを渡して最大値を聞く」は誤答する。

---

## 2. Decision

### 2.1 ツールは5つだけ。すべて読み取り

`get_latest` / `query_series` / `get_stats` / `list_alerts` / `describe_system`
（要件 §7.3）。**任意 SQL も受け付けない。** 引数は型で縛り、未知の項目は弾く。

「書き込み系を書かない」を規約ではなく**構造**で守る。`ai/` 配下に
`subprocess` / `eval` / `exec` / `compile` / `os.system` が無いことを
**構文木で検査する**（文字列の一致では、コメント中の言及で落ちる検査になる）。

### 2.2 集計は SQL 側。モデルには言語化だけをさせる（FR-504）

`get_stats` は min/max/mean/p95/傾き/欠測率を返し、**系列は返さない。**
`query_series` は**最大200点**に落とす。モデルが `agg=raw` を指定しても上限は守る。

指定が無ければ期間から粒度を選ぶ（API の自動ダウンサンプルと同じ考え方。
決定記録 0009 §2.4）。

### 2.3 外部由来の文字列は**データとして囲む**（要件 §7.4）

デバイスの `err` やアラートの `detail` はモデルへの指示ではない。
`<data>…</data>` で囲み、**囲みを閉じられないよう `<` と `>` を落とす。**
制御文字は除き、長さも切る（長文で文脈を埋めさせない）。

数値が主なので攻撃面は小さいが、**小さいことと無いことは違う。**

### 2.4 環境固有の識別子はモデルへ出さない

`describe_system` は ROM ID を**末尾4文字だけ**返す。プローブの同定には足り、
識別子そのものは出ない。

モデルの出力は Claude へのエスカレーション（#39）で外へ出ることがある。
リポジトリに書かない（#41）のと同じ理由で、モデルにも渡さない。

### 2.5 モデルが何を寄こしても落ちない

存在しないツール、壊れた JSON、型の違う引数 — すべて**結果として**返す
（`{"error": ...}`）。例外にすると、会話が続かないだけでなく
呼び出し側（API / デーモン）まで巻き込む。

存在しないツールには**使えるものの一覧**を返す。モデルが次の手を選べる。

---

## 3. Consequences

### 良くなること

- 「LLM に権限を与えない」が**検査可能**になった。`ai/` に危険な呼び出しが
  入ればテストが落ちる
- 24時間ぶんの問い合わせでも、モデルへ渡るのは200点以下か統計量だけ
- 外部由来の文字列が指示として読まれる経路を1箇所（`as_data`）に絞れた

### 悪くなること・その緩和

| トレードオフ | 緩和策 |
|---|---|
| モデルが任意の集計を要求できない | 5つのツールで要件 §7.3 の用途は満たす。足りなければツールを足す（設計を通す） |
| `query_series` の粒度が要求と違うことがある | 返り値に実際の `agg` と点数を含める |
| ROM が伏せられ、完全一致の照合ができない | 照合は `PROBE_CHANGED`（#18）が DB 上で行う。モデルの仕事ではない |
| 検査は `ai/` 配下だけ | 他の層は書き込みを持つのが正しい。**LLM が触る層**に限って禁じる |

---

## 4. 却下した代替案

| 案 | 却下理由 |
|---|---|
| 任意 SQL を実行するツール | AGENTS.md ルール1 に真正面から反する。読み取り専用でも DoS と情報の取り回しの問題が残る |
| 生の系列をそのまま渡す | 算術が不安定で誤答する（FR-504） |
| `get_stats` にも系列を含める | 「集計だけ渡す」という区別が曖昧になる（2.2） |
| 外部文字列をそのまま渡す | 指示として読まれる経路を残す（2.3、要件 §7.4） |
| 危険な呼び出しの検査を文字列一致で行う | コメント中の言及で落ち、「うるさいので外す」検査になる（2.1） |
| ROM をそのまま渡す | エスカレーション（#39）で外へ出る。#41 と同じ理由（2.4） |
