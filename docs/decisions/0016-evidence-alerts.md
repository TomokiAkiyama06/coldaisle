## 1. Context

`RECIRCULATION` という英字のアラート名だけでは対応を判断できない。
一方で、ローカルモデルに「確度87%」と言わせても**その数字に根拠が無い。**

FR-508 と構想メモ §5.1 は Evidence 形式を求める。
**モデルの自信度ではなく、何が検証済みで何が未検証なのかを管理する。**

---

## 2. Decision

### 2.1 VERIFIED は**コードが組み立てる。モデルに書かせない**

モデルが書くのは **UNVERIFIED（未確認の論点）と確認手順だけ**である。

測定値と閾値判定をモデルに書かせると、**数値を幻覚できてしまう。**
「VERIFIED の各行が DB の実データと照合できる」という受入基準が、
プロンプトの言い回し次第になる。**構造で守る。**

| Level | 誰が保証するか | 例 |
|---|---|---|
| L1 | 値の妥当性（品質フラグ・統計） | 全センサーが `ok`、直近24hの平均 |
| L2 | ルールエンジン（決定論的） | 閾値 5.00 を 480 秒継続して発火 |
| L3 | LLM（**推測**） | 「エアコンの稼働状態が未確認」 |

**VERIFIED に入るのは L1 と L2 だけ。** L3 は UNVERIFIED と確認手順に入る。

### 2.2 確度の表現は**書かれていたら丸ごと捨てる**

プロンプトで禁じるだけでは足りない。出力を検査し、
「確度 / 確信度 / 信頼度 / confidence / 可能性が高い / N% の可能性」が
含まれていたら**その応答を採用しない。**

**行だけ消して残りを使うことはしない。** 指示を守れていない応答の
残りを信用する理由が無い。

`%` そのものは湿度で正当に使うため、確率の文脈だけを弾く。

### 2.3 生成は通知経路をブロックしない

発火の通知を先に送り、説明は**別スレッドで後から続ける**（#38）。
LLM は最長120秒かかりうる。取り込みループで待つと、その間のサンプルを取りこぼす。

- 説明スレッドは**自分の接続を開く**（接続はスレッド間で共有しない。0004 §2.8）
- 待ち行列は有界。溢れたら記録する（素のアラートは既に届いている）

### 2.4 説明は**発火を届けた相手にだけ**送る

連投の抑制も夜間の方針も通さない（元の通知は既に届いている）。
逆に、発火を届けていない（夜間に抑制した warning など）なら説明も送らない。
決定記録 0013 §2.3 の解除と同じ考え方。

### 2.5 生成に失敗したら**説明を送らない**

素のアラートだけが届く（#38 のデグレード）。素のアラートには
ルール名・値・閾値・現在値が既に入っている（0013 §2.6）。

失敗とみなすのは、LLM が不達・JSON として読めない・確度の表現が含まれる場合。

### 2.6 モデルへ渡すのは**検証済みの事実だけ**

生の時系列は渡さない（0015 §2.2）。渡すのは L1 / L2 の行と、
アラートの識別情報のみ。モデルの仕事は**言語化と論点の提示**であって、
数え上げではない。

## 3. Consequences

### 良くなること

- 出力に確度の数値が入らないことが**構造で保証される**（2.1 / 2.2）
- LLM が落ちていても通知は届く。説明が付かないだけ（2.5）
- VERIFIED の各行が DB と照合できる。幻覚が混じる余地が無い

### 悪くなること・その緩和

| トレードオフ | 緩和策 |
|---|---|
| 説明が本文より遅れて届く | 素のアラートに値と閾値が入っている。遅れても判断は始められる |
| 応答を丸ごと捨てるので説明が付かないことがある | 素のアラートは届く。捨てた理由はログに残る |
| VERIFIED の内容が定型的 | 定型であることが照合可能性の裏返し。柔らかい記述は UNVERIFIED 側にある |

---

## 4. 却下した代替案

| 案 | 却下理由 |
|---|---|
| VERIFIED もモデルに書かせる | 数値を幻覚できる。受入基準がプロンプト次第になる（2.1） |
| confidence を出す（従来案 #24） | 根拠が無い。ローカルモデルの自己申告は信用できない（FR-508） |
| 確度の表現を含む行だけ削って使う | 指示を守れていない応答の残りを信用する理由が無い（2.2） |
| 取り込みループの中で生成する | LLM が最長120秒。その間のサンプルを取りこぼす（2.3） |
| 生成に失敗したら定型の説明を送る | 情報が増えない通知が増えるだけ。素のアラートで足りる（2.5） |
| モデルに生の系列を渡して要約させる | 算術が不安定で誤答する（0015 §2.2 / FR-504） |
