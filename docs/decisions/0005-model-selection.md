## 1. Context

Q-08（ローカルモデルの役割分担）は、Workspace 構想メモ（2026-08-12）の
**GPT-OSS-120B** と、2026-08-23 の指示にあった小型モデルが食い違ったまま、
0001 D-13 で「主軸 + 併用の二層構成」として暫定的に決まっていた。

その後2点が判明した。

1. **モデル名を読み違えていた。** 指示されていたのは `Qwen3-8B` ではなく
   **`Qwen3.8-27B`**（2026-08-14 公開、Apache 2.0、dense 27B）である
2. RTX PRO 6000 の 96GB に対し、**二層構成は VRAM に載らない**

二層構成の前提が数字の上で成立しないため、役割分担を詰める前に構成そのものを決め直す。

---

## 2. Decision

**Qwen3.8-27B を単体で採用する。** 大型モデルは併置しない。

| 構成 | 概算VRAM（96GB中） | 判定 |
|---|---|---|
| 120Bクラス + 27B BF16 | 120GB超 | 不可 |
| 120Bクラス + 27B FP8 | 95〜110GB | 不可 |
| **27B FP8 単体** | **30〜33GB** | **採用。余裕を KV プールに回せる** |

27Bクラスは 120B クラスと同等の水準にあるという報告があり、
**大型モデルを併置する前に、単体で不足するかを実測する**という順序を取る。

不足が確認された時点で上位モデルの追加を検討する。Provider 抽象（FR-501 / #21）が
あるため、差し替えは `OPENAI_BASE_URL` と `MODEL_NAME` の設定変更で済む。

### 2.1 D-14（常駐しない）は維持する

Compute Mode では vLLM を完全停止して VRAM を全解放する方針を変えない。
27B は 8B クラスより起動が遅くなるが、**空けることを優先する**という
構想メモ §40 の判断は VRAM 量ではなく用途の優先順位に基づくため、
モデルの大きさで結論が変わらない。

NFR-04（初回トークンまで2秒）はサービス稼働中の応答についての要件であり、
コールドスタートの時間は含まない。混同しないこと。

### 2.2 導入時に実物で確認すること

- vLLM が Blackwell (sm_120) でこのモデルを動かせること。
  Qwen3.5系以降は Gated DeltaNet を使うため、ランタイムのバージョン要件がある
- HuggingFace のリポジトリ ID（`Qwen/Qwen3.8-27B` を想定）
- ツールコールパーサの推奨値（vLLM / モデルのバージョンで変わる）

いずれもスモークテスト（#27）で確認する。**本記録の数値は見積りであり、実測ではない。**

---

## 3. Consequences

### 良くなること

- 常駐プロセスが1つになる。起動・停止・監視の対象が減り、#32 の
  Core / GPU サービス分割が単純になる
- VRAM の余裕を KV プールに回せる。長い文脈を扱えるほうが、
  日次レポート（FR-506）とアラート説明（FR-505）では効く
- #31 の論点（8B / 120B の役割分担）が消える。分担表を維持する必要がなくなる

### 悪くなること・その緩和

| トレードオフ | 緩和策 |
|---|---|
| 重い相関分析の逃げ場が無くなる | Claude へのエスカレーション（FR-509 / #39）が受ける。もともと「初見の異常パターン」は Claude の担当だった |
| 27B は 8B より起動が遅い | D-14 のとおり停止を優先する。起動待ちは Compute → AI の切り替え時のみ発生する |
| 実測で不足した場合、決め直しになる | Provider 抽象で差し替え可能。決め直しのコストは設定変更に収まる |
| モデルの選定根拠が「報告がある」に留まる | #27 のスモークテストで実測する。本記録は実測前の選定であることを明記した |

---

## 4. 却下した代替案

| 案 | 却下理由 |
|---|---|
| 二層構成を維持（0001 D-13） | 96GB に載らない。FP8 でも 95〜110GB |
| 8B クラス単体 | 96GB を使い切れない。単体構成にする以上、余裕がある側に寄せるほうが自然 |
| 120B クラス単体 | 60GB 前後を常時占有する。Compute Workload が主目的（#27）という前提と噛み合わない |
| 実測してから決める | 実測には実機が要る。#21 / #26 の設計を止めないため、先に既定値を置く |
