## 1. Context

2026-10-14 に 0121 の T5 を行った。(ii) 定常の GPU 600 W は、fand の auto で温度が落ち着くのを待つ間に、負荷の開始から
約 80 s で GPU コアが 80 °C に届いた。80 °C は、試験のスクリプトの中止の見張りの値で、0121 §2.1 の中止の基準 83 °C の
3 °C 手前である。そこで負荷を止めた。

- その間、fand の Demand は Fallback により 0.70 → 0.96 と上がっていた。筐体の Fan をほぼ全開にしても、GPU コアの上がりは
  止まらなかった（36 → 80 °C、上がり方はほぼ一定）
- BIOS の制御でも、GPU 600 W の 5 分で GPU コアは 84 °C になった（2026-10-13 の負荷試験）
- GPU の熱は主に GPU 自身の Fan で冷える。筐体の Fan の Demand で GPU 600 W の定常の温度を中止の基準より下に保つことはできない

したがって、0121 のとおりの「GPU 600 W で落ち着いた後に止める」(ii) と、「GPU 600 W を 10 分」の (iii) は、
中止の基準の内側では行えない。

## 2. Decision

### 2.1 (ii) の GPU の高い段階は 450 W にする

(ii) の GPU 600 W の段階を、電力の上限 450 W（`nvidia-smi -pl 450`）に置き換える。2026-10-14 の試行では、450 W で
GPU コア 75 °C・fand の Demand 0.85 で落ち着いた。

### 2.2 (iii) の GPU の温めは 450 W で 10 分、再開は 600 W

(iii) の GPU は、450 W で 10 分温めてから止め、Demand がアイドルの値 + 0.05 以内に戻った直後に、先に `SIGSTOP` してから
GPU 600 W（上限を既定に戻した状態）を始める。再開の負荷は 0121 のとおり 600 W のままとする。

### 2.3 GPU 600 W の上がりは (i) と (iii) で押さえる

止めてから Max までは約 5 s で、600 W の上がりは (i) と (iii) で測っている。(iii) は、450 W で 10 分温めた後に 600 W を始めた。
このときの上がりは、GPU コアで 49 → 68 °C（Max の後 30 s まで）だった。600 W の定常は、fand が動いていても中止の基準を超える。
そのため、その状態で fand が止まる場合の評価は、T5 の範囲外とする（GPU 自身の保護と、0121 §2.9 の T7 の扱いに委ねる）。

### 2.4 T5 の結果

8 条件（(ii) アイドル・GPU 300 W・GPU 450 W・CPU 全スレッド、(i) GPU 600 W・CPU 全スレッド、(iii) GPU・CPU）のすべてで、
次のとおりだった。

- 位相（`SIGSTOP` の時刻 - systemd が最後の `WATCHDOG=1` を受けた時刻）は 0.8〜8.0 ms
- `SIGSTOP` から Max（3 zone の `pwmN_enable=0`）までは 5143〜5294 ms で、約 11 s 以内
- 開始の温度 + 上昇の最高は CPU 76 °C・GPU 75 °C・12V-2x6 46 °C で、上限より 5 °C 以上低い

よって T5 は合格とし、`watchdog_timeout_ms` 5000 を 0121 §2.10 の時点で `confirmed` にする。

Max までが約 5 s だったのは、systemd が止まったプロセスにも `SIGABRT` を届け、`TimeoutAbortSec` の SIGKILL を待たずに
ExecStopPost の引き継ぎが走ったためである。0119 §2.12 の最悪約 11 s は、この経路が遅れたときの上限として残す。

## 3. Consequences

### 良くなること

- 中止の基準を緩めずに T5 を終えられる
- GPU 600 W の上がりは、(i) のアイドルからと (iii) の温まった状態からの2つで測れている

### 悪くなること・その緩和

- 「GPU 600 W の定常で fand が止まる」場合を測っていない。この状態は fand が動いていても中止の基準を超えるので、
  筐体の Fan の制御で守れる範囲の外にある。GPU 自身の温度の保護（driver の slowdown）が働く
- 450 W の定常の Demand（0.85）は 600 W の定常より低いので、(ii) のうち Demand が高い側の開始の状態は CPU 全スレッド
  （Top 1.0）で押さえる

## 4. 却下した代替案

| 案 | 却下の理由 |
|---|---|
| GPU の中止の基準（83 °C、見張りは 80 °C）を上げて 600 W の定常を作る | 安全の基準を緩める。T5 の目的（watchdog の時間と温度の余裕）は 450 W と (i)・(iii) で測れる |
| GPU 600 W の (ii) と (iii) を省く | (iii) の「温まった状態からの再開」の条件が無くなる。450 W で温めれば行える |
| 600 W を中止の手前まで（約 60 s）かけてから止める | 落ち着いた状態ではなく、(ii) の目的（定常からの開始）にも (iii)（温まった後に Demand が下がった状態）にも合わない |
