## 1. Context

0128 の曲線（45 °C 30 % / 55 °C 50 % / 65 °C 80 % / 70 °C 以上 100 %）を導入先で有効にした（2026-10-14 19:54）。
GPU 600 W では 100 % になり、71 °C で落ち着いた（同日 20:11〜20:30、fand は本番の設定の auto、筐体の Fan 0.77）。
所有者から、高い負荷と中くらいの負荷で GPU の Fan がうるさいので、600 W で 80 °C に届かないぎりぎりで回してほしいと依頼があった。

GPU の Fan を固定して GPU 600 W をかけ続け、落ち着く温度を段ごとに測った（2026-10-14 22:18〜22:36、`gpu80-2218-*`）。
試験の間だけ、fand の Fallback の曲線の Front / Rear の入力から `gpu.0.core` を外した（所有者の判断。外さないと GPU の温度で
筐体の Fan が上がり、GPU の Fan だけの効きが分からない）。そのため筐体の Fan は CPU の温度だけで決まり、3 zone とも 0.69 だった。

| GPU の Fan | 落ち着いた GPU コア | GPU の排気 | 吸気 |
|---|---|---|---|
| 80 % | 75 °C | 49.0 °C | 20.9 °C |
| 70 % | 78 °C | 53.0 °C | 21.0 °C |
| 60 % | 81 °C | 57.6 °C | 20.8 °C |

「落ち着いた」は、5 分以上かけた後の直近 3 分の幅が 1 °C 以内（整数で出る）。排気はまだ少しずつ上がっていたので、
真の定常は各段 +1 °C ほど高いかもしれない。3 点は `GPU コア ≈ 99 − 0.3 × 回転[%]`（吸気 21 °C のとき）でよく合う。

## 2. Decision

### 2.1 曲線（`provisional`）

| GPU コア | 回転 |
|---|---|
| 45 °C 以下 | 30 %（NVML の最小。アイドルは今と同じ） |
| 60 °C | 40 % |
| 70 °C | 50 % |
| 76 °C | 60 % |
| 80 °C | 75 % |
| 83 °C 以上 | 100 % |

unit の引数は `--curve 45:30,60:40,70:50,76:60,80:75,83:100`。点の間は直線で補う。引数の検査（温度は真に増加・回転は減らない・
NVML の範囲・最後の点は 100 %）、上げはすぐ・下げは 2 °C のヒステリシスと 1 %/s、止まったときに既定の制御へ戻すこと
（0128 §2.2〜§2.5）は変えない。

見込み（§1 の関係から。筐体の Fan が 0.69 のとき）:

- 600 W・吸気 21 °C: 約 78 °C・約 69 % で落ち着く（今の 100 % から 31 % 下がる）
- 600 W・吸気 26 °C（室温が 5 °C 高い）: 約 80.4 °C・約 79 %。83 °C で 100 % なので、それより上は今と同じ全開で守る
- 中くらいの負荷（55〜65 °C）: 今の 50〜80 % が 37〜45 % になる
- 本番では fand の Fallback の曲線が `gpu.0.core` で Front / Rear を上げる（75 °C 0.85・82 °C 1.0。§2.3）ので、GPU は上の
  見込みより低く落ち着く（筐体の Fan はその分上がる）

余裕: GPU の上限（T.Limit 推定 93 °C・slowdown 95 °C）と fand の `absolute_temp_ceiling_c` 90 °C に対し、600 W の定常で約 10 °C。
0121 §2.7 の T5 の合格の条件（開始の温度 + 上昇が 90 °C より 5 °C 以上低い）は、fand を止めている間も本サービスが曲線を書き続ける
ので、開始の温度 約 78 °C に対して満たす見込み（§2.4 で確かめる）。

### 2.2 試験の中止の基準の `gpu.0.core` を 85 °C にする

0121 §2.1 の中止の基準のうち `gpu.0.core` 83 °C を 85 °C にする（所有者の判断）。600 W の定常が 78〜80 °C になり、83 °C では
室温の変動で試験が止まるため。試験のスクリプトは中止の基準そのもの（85 °C）で負荷を止める。`cpu.package` 88 °C・
`board.connector_12v2x6` 70 °C は変えない。85 °C は GPU の上限（93 °C）と `absolute_temp_ceiling_c` 90 °C より低い。

### 2.3 筐体の曲線は本番では変えない

§1 の測定で Front / Rear の入力から `gpu.0.core` を外したのは試験の間だけで、本番の `fan-policy.yaml`（0119 §2.14）は変えない
（所有者の判断）。GPU が 78 °C 前後になると、fand は Front / Rear を約 0.91 に上げる（71 °C では 0.77）。筐体の Fan の音が
問題になれば、Fallback の曲線の扱いを別の決定記録で決める。

### 2.4 導入先での確認（配置の後）

1. 曲線を書き換えた unit を配置し、アイドルで 30 % のままであること
2. fand を本番の設定・auto で動かし、GPU 600 W を 15 分: GPU コアが 85 °C 未満で落ち着き、回転が 100 % 未満であること
3. 0121 T5 の ii-gpu600・iii-gpu600 を、この曲線でやり直す（中止の基準は §2.2）。結果で 0127 の扱いを決める

## 3. Consequences

### 良くなること

- 600 W で GPU の Fan が全開にならない（約 70 %）。中くらいの負荷でも回転が下がる

### 悪くなること・その緩和

- GPU が 7 °C ほど熱くなる（600 W で 71 → 約 78 °C）。上限まで約 10 °C の余裕は残る
- fand が GPU の温度で Front / Rear を上げるので、筐体の Fan の音が増える（§2.3）
- 室温が高いと 80 °C を超えうる（吸気 26 °C で約 80.4 °C の見込み）。83 °C 以上は 100 % で、今と同じ守り方になる
- `coldaisle-gpu-fan` が止まったときは、今と同じく GPU 自身の既定の制御（静音寄り）に戻る。そのときの 600 W の振る舞いは
  0128 §1 のとおり（約 80 s で 80 °C）で、この記録で変わらない

## 4. 却下した代替案

| 案 | 却下の理由 |
|---|---|
| 0128 の曲線のまま | 所有者の依頼（静かにする）に応えない |
| 目標の温度を中心にした PI 制御 | 曲線の傾きを目標の近くで急にすれば同じ効果になる。決定論的な曲線のほうが確かめやすい（0128 §4） |
| 本番の筐体の曲線からも `gpu.0.core` を外す | GPU の熱は筐体の中の空気を温める。所有者の判断で、筐体の曲線は試験の間だけ変える（§2.3） |
| 80 °C で 70 %・83 °C で 100 %（もっと静か） | 600 W で 79〜80 °C、室温 +5 °C で 82 °C 前後。中止の基準（85 °C）までの余裕が小さい |
