## 1. Context

2026-10-14 に 0121 の T6 を行った。検出（`stall_min_rpm` を上げた設定で `tach_stall` が上がるまで）は 3 zone とも合格した。
立ち上がりは次のとおりで、0121 の「3 回の最長が 2500 ms（窓の半分）未満」を Top と Rear が満たさなかった。

| zone | 測ったもの（PWM を書いた時刻から） | 3 回 |
|---|---|---|
| Top | `stall_min_rpm` 450 RPM 以上 | 2246 / 2136 / 2688 ms |
| Front | `stall_min_rpm` 300 RPM 以上 | 1121 / 1457 / 1008 ms |
| Rear | 0.35 の回転数の 90% 以上（0.0 の間の最低は 439〜442 RPM） | 3696 / 2915 / 2685 ms |

記録を確かめて分かったこと:

- この基板（nct6799）の `fanN_input` は、約 1576 ms ごとにしか値が変わらない（3 zone とも。0.1 s ごとの読み取りで、
  値が変わる間隔の中央値 1576 ms）。立ち上がりの時間は、この周期の刻みでしか見えない。Top の 3 回目は、書き込みから
  1119 ms で 370 RPM、次の更新の 2688 ms で 684 RPM だった。450 RPM を実際に超えたのはこの間のどこかである
- fand も同じ `fanN_input` を読んで stall を判定する。fand から見た立ち上がりの時間も同じ刻みで、更新の位相によって
  最大でほぼ1周期分ばらつく。0121 の「窓の半分」は、この刻みを考えていない
- Rear は PWM 0 でも 439 RPM 以上で回り、`stall_min_rpm`（350）を下回らない。Rear の立ち上がりの時間は stall の計時に
  関わらない

## 2. Decision

### 2.1 `stall_window_ms` は 5000 のまま

窓は延ばさない。延ばすと、本物の stall（Fan の故障）を見つけて Max にするまでが同じだけ遅れる。

### 2.2 立ち上がりの合格の条件を「最長 + tach の更新の周期 < 窓」にする

0121 §2.8 の「止まった状態から `stall_min_rpm` まで」の合格の条件を、次に置き換える。

- 3 回の最長に、tach の更新の周期（導入先では 1600 ms。測った 1576 ms を切り上げた値）を足した値が、`stall_window_ms` 未満

更新の周期を足すのは、更新の位相が悪い試行では、fand から見た時間が最大でほぼ1周期長くなりうるため。
2026-10-14 の結果は、Top が 2688 + 1600 = 4288 ms、Front が 1457 + 1600 = 3057 ms で、どちらも 5000 ms 未満なので合格とする。

tach の更新の周期は、試験の 0.1 s ごとの記録で、回っている間に `fanN_input` の値が変わる間隔の中央値として測る。
基板や driver を変えたときは測り直す。

### 2.3 Rear の 90% までの時間は記録だけにする

Rear の「0.0 の間の最低の回転数が 350 RPM より高い」は合否の条件として残す（2026-10-14 は 439 RPM で合格）。
「0.35 の 90% までの時間が 2500 ms 未満」は、Rear が `stall_min_rpm` を下回らず stall の計時に関わらないので、
値として記録し、合否にしない。

## 3. Consequences

### 良くなること

- 立ち上がりの条件が、fand が実際に見る tach の刻みに合う
- 本物の stall を見つける速さは変わらない

### 悪くなること・その緩和

- 余裕の条件が緩む（窓の半分 2500 ms → 窓から1周期を引いた 3400 ms）。fand から見た最悪の時間（最長 + 1周期）が
  窓の内側に収まることは保つので、止まった Fan を立ち上げるときに stall と誤って判定しない
- Rear の応答の速さは合否から外れる。値は結果に残す

## 4. 却下した代替案

| 案 | 却下の理由 |
|---|---|
| `stall_window_ms` を 7500 に延ばす | 今の条件のままで合格するが、本物の stall の検出が 2.5 s 遅れる |
| 回数を増やして測り直す | 更新の周期は変わらないので、最長はおそらく 3 s 前後になり、今の条件を満たさない |
| 0121 を書き直す | 決定記録は書き換えない（追記のみ）。一部を置き換える新しい記録にする |
