# Airflow specification sources

Manufacturer specifications used as priors for the v1 airflow model:

- Noctua NF-A12x25 G2 PWM: maximum 1800 RPM, 63.15 CFM, 3.14 mmH2O per fan.
- Cooler Master MasterLiquid Atmos II 360: maximum 2500 RPM, 190 CFM aggregate fan airflow, 3.61 mmH2O.
- Antec FLUX included rear fan: case documentation identifies a 140mm PWM rear fan, but a reliable standalone airflow specification has not been established; characterize it on the server.

These values are metadata only. They are not treated as installed-case airflow measurements.
