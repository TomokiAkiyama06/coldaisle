## 背景
室温がすでに32°Cある真夏の昼に600W連続負荷を開始するのは危険。
しかし **「AIが判断してCompute Modeを拒否する」設計にしてはいけない。**
ユーザーのKaggle実行を止める権限をAIに与えることになる。

## 方針: 警告のみ。ブロックしない。

構想メモ §35 の Permission UI と同じ思想。**判断材料を出す。決めるのは人間。**

```text
Compute Mode へ切り替えますか？

⚠ 現在の環境条件
  室温     31.2°C  （通常時 26.4°C / +4.8°C）
  GPU吸気  34.8°C
  湿度     68%     （結露リスク閾値に接近）

前回のフルロード時（2026-08-15、室温26.1°C）は
GPU hotspot が最大 91°C に達しました。
現在の室温はその時より 5.1°C 高い状態です。

[ 切り替える ]  [ やめる ]
```

## やること
- [ ] `compute_mode_advisory` を `server-health` に含める（`safe`, `warnings[]`）
- [ ] **判定は決定論的に行う**（Safety-1）。AIは文面生成のみ、または不使用
- [ ] 過去のフルロード実績との比較データを含める
- [ ] Workspace側の切替ダイアログで表示

## 受入基準
- **どんな条件でも切替をブロックしない**（警告を出すだけ）
- AI停止中でもアドバイザリが機能する（決定論的なので当然機能すべき）
