## 背景

本リポジトリは public です。認証情報や環境固有の情報が一度でも push されると、
履歴に残り、force push でも完全には消えません。**最初のコミット前に整備します。**

## やること

### 秘匿情報を入れない仕組み

- [ ] `.gitignore` に以下を追加
      `.env` / `.env.*`（`.env.example` を除く）/ `*.db` / `*.sqlite3` /
      `config/secrets.*` / `logs/` / `*.log`
- [ ] `.env.example` を用意し、**変数名だけ**を示す（値は空）
- [ ] Webhook URL・APIトークン・パスワードをコードにもドキュメントにも書かない
- [ ] 設定値はすべて環境変数または `config/*.yaml` から読む。ソースに直書きしない

### 環境固有情報を含めない

- [ ] IPアドレス・ホスト名・MACアドレス・シリアル番号を含めない
- [ ] ネットワーク構成図を含めない
- [ ] 個人・組織を特定できる記述を含めない
- [ ] スクリーンショットを載せる場合、上記が写り込んでいないか確認する

### ライセンスと表記

- [ ] `LICENSE` を配置（**Apache-2.0 を推奨**。Qwen3 と同一で整合が取れ、特許条項もある）
- [ ] `README.md` に著作権表記を追加

### 継続的な検出

- [ ] `detect-secrets` 等を pre-commit フックに導入
- [ ] 同じチェックを CI にも入れる
- [ ] **初回 push 前に `git log -p` を目視で確認する**

## 受入基準

- `.env` および実データベースがコミットされていない
- pre-commit と CI で秘匿情報パターンが検出される
- LICENSE が配置されている
- リポジトリ単体を読んで、稼働環境や運用主体が特定できない
