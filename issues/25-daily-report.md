## やること
- [x] 毎朝、前日分の統計（最高/最低/平均、アラート件数、前日比、欠測率）を集計
- [x] LLMで要約文を生成
- [x] 通知先へ投稿できる構成
- [x] Markdownで `var/reports/` に保存

## 設計上の決定
- レポートは生成物なので `docs/reports/` ではなく **`var/reports/`** に保存する
- 集計元は1分ロールアップを使う。生データ保持期間を過ぎても再生成できること
- データが無い/不足している場合は黙って補完しない
- LLM所見に表にない数値が含まれる場合は採用しない
- 通知はアラート用 Router とは分離する

## 受入基準
- データ欠損を含む1日分のDBからレポートを生成できる
- 欠測と「収録されなかった時間」を区別して表示できる
- AIが利用できなくても測定値表だけでレポートが成立する
